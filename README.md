# Econometrics

## Estatística (`stats/`)

|---|---|---|
| 2 | Medidas descritivas | [`stats/02-medidas-descritivas/index.html`](stats/02-medidas-descritivas/index.html) |

Cada conteúdo é uma página HTML autocontida (abre direto no navegador) com:
teoria e fórmulas, exemplo aplicado, código em Python, R, Stata e Excel,
calculadora interativa e exercícios com gabarito. Os dados e scripts ficam
nas subpastas `dados/` e `codigo/` de cada conteúdo.

### Publicar como site

Em *Settings → Pages*, escolha *Deploy from a branch*, branch `main` e pasta
`/ (root)`. A página ficará em
`https://cleitonfranco74.github.io/econometrics/stats/02-medidas-descritivas/`.
